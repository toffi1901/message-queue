# Очередь сообщений – лабораторная работа по ООП (C++)

Реализация классов `Message` (простой) и `MessageQueue` (сложный) с последующей перегрузкой операторов, ручным управлением динамической памятью (для учебных целей) и модульным тестированием.

## Цель работы

- Разработать простой класс `Message` (текст, чат, время).
- Разработать сложный класс `MessageQueue` (очередь сообщений на основе статического массива, затем – динамического).
- Перегрузить операторы `=`, `<<`, `>>`, `+=`, `[]` и др.
- Реализовать консольный диалоговый интерфейс для отладки.
- Покрыть код модульными тестами (Google Test) с покрытием ≥80%.
- Подготовить документацию с помощью Doxygen.

## Требования к проекту

- **Стандарт C++20** (или C++23).
- Сборка через **CMake** (≥3.12).
- Использование **Google Test** для модульного тестирования.
- **Статический анализ** кода (например, Clang-Tidy, включённый в CMake).
- **Динамический анализ** памяти (Valgrind / Dr. Memory) – отсутствие утечек.
- Документирование всех публичных методов через **Doxygen**.
- Корректное завершение программы без `exit`, `abort`, `std::terminate`.
- Предпочтение высокоуровневых конструкций C++ (std::string, исключения) вместо C-функций.
